# Template

El template ejecutable y su especificación viven en
[acandaldev/openspec-software-factory-template](https://github.com/acandaldev/openspec-software-factory-template).

Este repositorio solo publica el sitio del método. Para adoptarlo, crea el
proyecto desde el template y ejecuta `node bootstrap.mjs`.

El contrato legible por máquina está en `data/template.json`; el check de
sincronía compara esa copia con la del template.
