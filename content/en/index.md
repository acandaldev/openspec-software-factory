# The factory that executes your specifications

OpenSpec defines **what must be true**. This factory adds **who executes it**, with what evidence, and how the system that executes it gets corrected.

It is not a long prompt or a chatbot with tools. It is a method with four parts, four loops and one rule: every decision leaves a trace in git.

This page is the full tour: the problem, the parts, the loops, the agents and the gates. If you want to see the method in action, start with the [full example](ejemplo.html). To learn how it is run or adopted, use the other tabs.
