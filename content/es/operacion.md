# Cómo se opera

El método no se sostiene con prompts: se sostiene con documentos que no mienten, pocos scripts con dueño, un curador que corrige reglas y una capa de conocimiento opcional.

Esta página reúne lo que mantiene la fábrica en el tiempo: documentos, scripts, curador y, si hace falta, una capa de conocimiento opcional.
